# 🎓 Campus Placement Management System

## 📌 Overview
The Campus Placement Management System is a Spring Boot-based web application that automates the campus recruitment process. It helps administrators manage students, recruiters, job postings, applications, interviews, and placement activities through a centralized platform.

## 🚀 Features
- Student Management
- Recruiter Management
- Job Management
- Job Applications
- Interview Scheduling
- Resume Management
- JWT Authentication
- REST APIs
- MySQL Database Integration

## 🛠️ Technologies Used
- Java 17
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman
- Git & GitHub
